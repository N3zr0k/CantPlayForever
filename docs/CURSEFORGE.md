# CurseForge

## Summary
Clock with multiple alarms and timers for WoW Forever.

## Description
**Can't play Forever** replaces the minimap clock with a configurable clock that carries multiple alarms and timers.

* **Alarms**: daily, on chosen weekdays or on a date (monthly or yearly), once or repeating. Ctrl + left-click arms / disarms.
* **Timers**: several presets, start and stop with one click.
* **Original clock**: can be hidden; Ctrl + right-click opens the stopwatch, Alt + right-click the original clock menu.
* **Effects**: sound, chat message and an adjustable pulsing glow at the screen edge.
* English, German and French.
